    Create navigation system using SwiftUI NavigationStack (iOS 17+):

    1. Create Route.swift enum with all app routes:
       - auth (login/signup - Phase 2)

       - organizationDetail(id: UUID)
       - meetingList(orgId: UUID)

    Coordinator pattern centralizes navigation logic.
