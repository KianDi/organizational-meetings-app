<task type="auto">
  <name>Task 1: Create OrganizationState for app-wide org management</name>
  <files>MeetingManager/State/OrganizationState.swift</files>
  <action>
Create @Observable OrganizationState following AuthState pattern:
- @Observable final class OrganizationState
- private(set) var organizations: [Organization] = []
- private(set) var isLoading: Bool = false
- private let organizationService: OrganizationService
- init(organizationService: OrganizationService = OrganizationService())
- @MainActor func loadUserOrganizations(userId: UUID) async throws
  - Set isLoading = true
  - Fetch user's organization_ids from users table
  - For each org ID, fetch full Organization
  - Set organizations array
  - Always set isLoading = false in defer block
- @MainActor func createOrganization(name: String, adminId: UUID) async throws -> Organization
  - Call organizationService.createOrganization
  - Append to organizations array
  - Return created org
- @MainActor func joinOrganization(inviteCode: String, userId: UUID) async throws -> Organization
  - Call organizationService.findByInviteCode
  - Call organizationService.joinOrganization
  - Call organizationService.updateUserOrganizations
  - Append to organizations array if not present
  - Return joined org
- @MainActor func refresh(userId: UUID) async
  - Reload organizations for user (call loadUserOrganizations, ignore errors)
- Follow Phase 2's AuthState pattern: @Observable, @MainActor methods, actor service dependency
  </action>
  <verify>Build succeeds, OrganizationState compiles</verify>
  <done>OrganizationState manages app-wide organization data</done>
</task>
