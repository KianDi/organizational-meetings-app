<task type="auto">
  <name>Task 1: Create CalendarView with unified multi-organization monthly grid</name>
  <files>MeetingManager/MeetingManager/Views/Calendar/CalendarView.swift</files>
  <action>
Create CalendarView showing ALL events from ALL organizations in one unified calendar:

**Structure:**
- NavigationStack with "Calendar" title
- Month/year header with previous/next month arrows
- 7-column weekday header (S M T W T F S)
- Grid of day cells (42 cells for 6 weeks to cover all months)
- Selected day detail section below grid
- Pull-to-refresh to reload all data

**Day cell design:**
- Date number (primary for current month, gray for adjacent months)
- Multi-colored indicator dots below date (stacked or side-by-side):
  - Each organization gets a unique color for its events
  - Blue dot for meetings, green dot for tasks (with organization-specific shading)
  - Multiple dots if events from multiple organizations on same day
- Highlight selected day with rounded background
- Today's date with circle border

**State:**
- @Environment(MeetingState.self) for all meetings and tasks
- @Environment(OrganizationState.self) for organization list and colors
- @State var selectedDate: Date = Date() (defaults to today)
- @State var displayMonth: Date (tracks which month is shown)
- Computed properties:
  - daysInMonth: [Date] (array of dates for grid cells)
  - allMeetingsForDate: [Date: [Meeting]] (meetings from ALL organizations)
  - allTasksForDate: [Date: [MeetingTask]] (tasks from ALL organizations)

**Multi-organization handling:**
- Load meetings from ALL organizations user belongs to
- Load tasks from ALL organizations
- Use organizationId from each event to determine color
- Create color map: organizationId → Color (consistent colors per org)
- Display color-coded dots on calendar cells

**Grid layout:**
- LazyVGrid with 7 columns (fixed size)
- Each cell 44x44 points minimum
- Tap cell to select date and show detail

**Month navigation:**
- Previous month button: subtract 1 month from displayMonth
- Next month button: add 1 month to displayMonth
- Update grid when displayMonth changes

**Data processing:**
- Group ALL meetings by scheduledAt date (ignore time, match on day)
- Group ALL tasks by dueDate (ignore time, match on day)
- Maintain organizationId with each event for color coding
- Update dictionaries when data changes

**Organization color scheme:**
- Assign consistent colors to each organization
- Use Color palette: .blue, .green, .orange, .purple, .red, .pink, .indigo, .teal
- Store mapping in @State var orgColors: [UUID: Color]

**Why this approach:**
- Unified view simplifies user workflow across all organizations
- Color coding provides visual distinction without clutter
- LazyVGrid provides efficient grid layout
- Dictionary grouping enables O(1) lookup for indicators
- Native Calendar API for date calculations

Create CalendarDayView component to display all meetings and tasks from all organizations for a selected date:

**Props:**
- date: Date (the selected date)
- meetings: [Meeting] (all meetings on this date from all orgs)
- tasks: [MeetingTask] (all tasks due on this date from all orgs)
- orgColors: [UUID: Color] (organization color mapping)

**Structure:**
- Section header with formatted date (e.g., "Tuesday, January 28")
- Divider
- If no meetings and no tasks: "No events for this day" empty state
- If meetings exist:
  - "Meetings" subheader
  - List of meeting rows (grouped by organization):
    - Organization name badge with color
    - Blue calendar icon
    - Meeting title
    - Time (formatted as "3:00 PM")
    - NavigationLink to MeetingDetailView
- If tasks exist:
  - "Tasks Due" subheader
  - List using TaskRowView component (from Phase 5)
  - Organization name badge with color
  - Tap to navigate to meeting where task was created

**Organization badges:**
- Small capsule with organization name
- Background color matches organization's assigned color
- White text for contrast
- Positioned at leading edge of row

**Date formatting:**
- Header: "EEEE, MMMM d" (Tuesday, January 28)
- Meeting time: "h:mm a" (3:00 PM)

**Layout:**
- Rounded background (12pt radius)
- Padding (16pt)
- Spacing between sections (12pt)
- Group events by organization for clarity

**Why this approach:**
- Organization badges provide clear context for multi-org events
- Reuses TaskRowView for consistency
- Color coding matches calendar grid for visual continuity
- NavigationLink enables context navigation to meeting detail
- Grouping by organization improves readability
