<task type="auto">
  <name>Task 1: Create CalendarView with monthly grid and event indicators</name>
  <files>MeetingManager/MeetingManager/Views/Calendar/CalendarView.swift</files>
  <action>
Create CalendarView with native iOS calendar grid using Calendar API:

**Structure:**
- NavigationStack with "Calendar" title
- Month/year header with previous/next month arrows
- 7-column weekday header (S M T W T F S)
- Grid of day cells (42 cells for 6 weeks to cover all months)
- Selected day detail section below grid
- Pull-to-refresh to reload data

**Day cell design:**
- Date number (primary for current month, gray for adjacent months)
- Indicator dots below date:
  - Blue dot: meetings scheduled (1+ meetings)
  - Green dot: tasks due (1+ incomplete tasks)
  - Both dots if both types present
- Highlight selected day with rounded background
- Today's date with circle border

**State:**
- @Environment(MeetingState.self) for meetings and tasks
- @Environment(OrganizationState.self) for current org
- @State var selectedDate: Date = Date() (defaults to today)
- @State var displayMonth: Date (tracks which month is shown)
- Computed properties:
  - daysInMonth: [Date] (array of dates for grid cells)
  - meetingsForDate: [Date: [Meeting]] (dictionary grouped by date)
  - tasksForDate: [Date: [MeetingTask]] (dictionary grouped by due date)

**Grid layout:**
- LazyVGrid with 7 columns (fixed size)
- Each cell 44x44 points minimum
- Tap cell to select date and show detail

**Month navigation:**
- Previous month button: subtract 1 month from displayMonth
- Next month button: add 1 month to displayMonth
- Update grid when displayMonth changes

**Data processing:**
- Group MeetingState.meetings by scheduledAt date (ignore time, match on day)
- Group MeetingState.organizationTasks by dueDate (ignore time, match on day)
- Update dictionaries when data changes

**Why this approach:**
- LazyVGrid provides efficient grid layout
- Dictionary grouping enables O(1) lookup for indicators
- Separate CalendarDayView component (next task) for selected day detail
- Native Calendar API for date calculations (no external dependencies)
- Indicator dots provide visual density without clutter

**Layout:**

**Why this approach:**
