  <action>
Create TaskListView that displays ALL tasks from ALL organizations the user belongs to:

**Structure:**
- NavigationStack with "Tasks" title
- Toolbar with filter menu (All Tasks / My Tasks / Unassigned)
- Segmented picker for completion filter (All / Active / Completed)
- List grouped by sections: Overdue, Today, This Week, Later, Completed
- Each row uses TaskRowView component from Phase 5
- Organization badge/label on each task row (to distinguish which org the task belongs to)
- Empty state with "No tasks yet" message and icon
- Pull-to-refresh to reload all tasks

**State management:**
- @Environment(MeetingState.self) for task data
- @Environment(OrganizationState.self) for organization list and member names
- @State private var authState: AuthState for current user ID
- @State for filter selections (assigneeFilter, completionFilter)
- Computed property for filtered tasks based on selections

**Multi-organization handling:**
- Load tasks from ALL organizations user belongs to
- Display organization name with each task (use organization color or badge)
- Tasks maintain organizationId field to show which org they're from
- Fetch organization names from OrganizationState.organizations

**Filtering logic:**
- Assignee filter: All (no filter), My Tasks (assigneeId == currentUserId), Unassigned (assigneeId == nil)
- Completion filter: All (no filter), Active (!isCompleted), Completed (isCompleted)

**Sorting/grouping:**
- Overdue: !isCompleted && dueDate < today
- Today: !isCompleted && dueDate == today
- This Week: !isCompleted && dueDate <= 7 days from now
- Later: !isCompleted && (dueDate > 7 days OR dueDate == nil)
- Completed: isCompleted (sorted by completion date desc if available, otherwise by due date)

**Row interaction:**
- Tap checkbox to toggle completion (calls MeetingState.toggleTaskCompletion)
- Tap row to navigate to meeting detail where task was created
- Swipe to delete (admin/creator only)

**Organization indicator:**
- Small capsule badge next to task with organization name
- Use organization colors if available, otherwise use consistent color scheme
- Keep badge subtle (caption font, tertiary background)

**Why this approach:**
- Unified view across all organizations simplifies user workflow
- Organization badges provide context without clutter
- Reuses TaskRowView for consistency
- Groups provide clear organization and prioritization
- Filters enable personalization

<task type="auto">
  <name>Task 2: Add multi-organization task methods to MeetingState</name>
  <files>MeetingManager/MeetingManager/State/MeetingState.swift</files>
  <action>
Extend MeetingState with task methods that work across all organizations:

**Add properties:**
- `allUserTasks: [MeetingTask] = []` - cached tasks from ALL organizations
- `isLoadingTasks: Bool = false` - loading indicator

**Add methods:**

1. `loadAllUserTasks(organizationIds: [UUID]) async throws`:
   - Set isLoadingTasks = true
   - For each organizationId, call TaskService().fetchTasksForOrganization(organizationId)
   - Aggregate all results into allUserTasks array
   - Set isLoadingTasks = false
   - Handle errors with isLoadingTasks = false in defer block
   - @MainActor annotation

2. `toggleTaskCompletion(taskId: UUID) async throws`:
   - Find task in allUserTasks by id
   - Call TaskService().updateTaskCompletion(taskId, isCompleted: !currentValue)
   - Update local task in allUserTasks array with new completion status
   - If task also exists in a meeting's tasks array, update it there too
   - @MainActor annotation for UI updates

3. `deleteTask(taskId: UUID) async throws`:
   - Call TaskService().deleteTask(taskId)
   - Remove from allUserTasks array
   - Remove from any meeting's tasks array
   - @MainActor annotation

**Why this approach:**
- loadAllUserTasks aggregates across organizations for unified view
- Centralizes task state management in existing MeetingState
- Local array updates provide instant UI feedback
- Multiple cache update (allUserTasks + organizationTasks + meeting.tasks) prevents stale data
- Actor isolation ensures thread safety
