    - iOS 17.0 or later deployment target

    1. Create new Supabase project at supabase.com

    1. Create account at openrouter.ai

    3. Generate API key from dashboard
    4. Update OpenRouterConfig.swift with your key

    2. Select iPhone simulator (iOS 17+)
    3. Build and run (Cmd+R)
    4. Create account on signup screen
